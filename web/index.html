Test mode

Overrides DDP input for every enabled zone until switched off.

Zones

Each zone is one set of bracelets that share an address. Zones take consecutive DDP channels from the start channel (). Disabling a zone keeps the channel layout.

#OnNameGroup / addressChannelsTest

Zone walk

Lights one saved zone at a time so you can see which bracelets belong to which zone. Wake the bracelets first (press their button). Pause xLights while walking, or its input will overwrite the colours. Unsaved zone edits are not used: save first.

Radio

Strong 433 MHz signals can stop some car key fobs working nearby. Use the lowest TX power that reaches your audience, keep refresh at 0, and don't keep the bracelets busy all show long.

Which bracelet do I have?

      
Switch a bracelet on, press its button so it listens, and hold it near the antenna. This alternates between the two bracelet protocols, each broadcast to all groups:
        red = protocol 0 (Shenzen New Dody), green = protocol 1 (LedGiftSupplier.com).

Display (OLED)

      

      

        
      

      

      

      
Wiring: SDA → IO5 (pin labelled RXD), SCL → IO17 (TXD), VCC → 3V3, GND → GND. The controller keeps looking at 0x3C and 0x3D every 5 s, so a fixed connection comes alive without a reboot.
