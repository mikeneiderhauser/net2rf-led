Receiver — heard on air

This controller is in receiver mode: it listens on 433 MHz and shows what every device group was last told, from any transmitter in range (this project, the vendor's DMX transmitter, a Flipper). It never transmits. Both device protocols are decoded at once.

Which protocol is my device?

      
Switch the device on, press its button so it listens, and hold it near the antenna. This alternates between the two device protocols, each broadcast to all groups:
        red = protocol 0 (Shenzen New Dody), green = protocol 1 (LedGiftSupplier.com).

      

        

      
Device showed:

      
Nothing at all? Check the device's power switch and battery, bring it closer, raise TX power, and confirm the radio shows ready on the dashboard.
        If it only reacts to protocol 1 once you pick a group, use the Address probe below on Group (byte 1) in sweep mode.

Firmware

      
Update firmware

        
Upload a firmware.bin build. The controller reboots when done.

        
        
File picker does nothing? You're in the Wi-Fi sign-in window: open http://192.168.4.1/ in Safari or Chrome.

        

        

        
From GitHub releases

        
Your browser asks GitHub for the latest release, downloads it and hands it to the controller, which only has to write it. The controller itself never contacts GitHub, so it needs no internet access. If this browser cannot fetch the file, download the .bin and use Upload above.

        

        

        
        

        

        

      

    

    
Display (OLED)

      

      

        
        
      

      

      

      
Wiring: SDA → IO5 (pin labelled RXD), SCL → IO17 (TXD), VCC → 3V3, GND → GND. The controller keeps looking at 0x3C and 0x3D every 5 s, so a fixed connection comes alive without a reboot.

    

    
Admin password

      

      

        
        
      

      

      
The dashboard and /api/stats stay readable without it. Forgot it? Hold the front-panel button 5 s (network reset) to clear it.

    

    
Configuration

      
The controller keeps two separate sets of settings: network (hostname, Ethernet / Wi-Fi, IP address, setup hotspot, admin password) and settings (everything else: zones, devices, radio, input, display, updates). Each is exported, imported and reset by itself.

      

      

        

      
An import replaces only the part the file holds. Exports never include the Wi-Fi or admin password.

    

    
Maintenance

      

      

        
        

      
Reset settings keeps the network connection. Reset network keeps your zones and radio settings, but the controller goes back to DHCP and forgets its Wi-Fi, so it may come up on another address or on its setup hotspot.

    

    
Diagnostics and stored files
      
The controller keeps a boot log, the transmitters receiver mode has heard and any captures you saved, as small JSON files. They survive restarts, firmware updates and a factory reset; a full flash erase removes them.
