Net2RF LED

Install the firmware on a WT32-ETH01 from your browser.

1 · Connect

  1. Wire a 3.3 V USB-serial adapter to the programming header: adapter TX → RX0 (IO3), adapter RX → TX0 (IO1), GND → GND. Power the board from 5 V.
  2. Enter flashing mode: hold BOOT, tap EN, release BOOT. (The WT32-ETH01 has no automatic reset, so do this before every install.)

2 · Install

Click Install, choose the adapter's serial port, and confirm. Erasing is recommended for a first install.

This browser can't flash devices. Use Chrome or Edge on a desktop computer. Flashing needs a secure (https) page.
If connecting fails with "Failed to initialize" or "Wrong boot mode", repeat the BOOT + EN step and try again.

3 · First start

  1. Tap EN to start the new firmware.
  2. With Ethernet plugged in, open http://net2rf.local/ (or find the IP on the OLED or in your router).
  3. No Ethernet? Join the Wi-Fi network NET2RF-XXXX (password net2rf1234); the setup page opens by itself.

Updating an installed controller? Use System → Update firmware in its web UI with firmware.bin from the latest release. No cable needed.
